# Stage: Explore
Goal: understand the problem before anything is planned. No code, no stories yet.

Do:
- Ask the user one question at a time, only what you can't find yourself: the problem, who it's for, what success looks like, constraints (stack, deadline, budget, client requirements).
- Existing code: read its structure, stack, conventions and test setup. Find the exact command that runs the tests.
- Note risks and unknowns.

Write `docs/explore.md`, one page max:
Problem · Users · Success · Constraints · Stack + how to run and test · Risks and unknowns · Open questions

Done when: the user agrees `docs/explore.md` is right. Next stage: `stories`.
